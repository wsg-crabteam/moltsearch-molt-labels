# CVforCrabID -- Computer Vision for Crab ID: Scaling Molt Search
Crab molt classifying for Molt Search submissions

## Why This Project?
The Molt Search program is growing, and to reach a scale useful to natural resource managers (WDFW) & Dungeness crab researchers, we need more reports from more places.
**Challenge:** To maintain a high quality dataset, every report currently must be reviewed and corrected by staff. This manual review step is a bottleneck that limits program growth.
**Opportunity:** Molt Search reports follow a standardized layout, making them ideal for computer vision. This project will explore how AI can help staff review reports more efficiently and accurately.

## Project Idea
* Develop a computer vision model to:
* Identify & count Dungeness and European green crabs from report images
* Flag difficult images for human review

## Steps to Success
* Partner with an external collaborator (e.g. AI for Conservation community)
* Prepare a dataset to develop & evaluate a computer vision model (student capstone?)
* Train & test a model (or launch a leaderboard to engage broader AI community)
* If successful, integrate into data workflows (e.g. MyCoast) and participant training plans

## Molt Search Program basics
<a href="wsg.washington.edu/moltsearch">Molt Search</a> is a participatory science program based in Washington State, USA. Washington Sea Grant and Washington State University Extension teamed up in 2023 to launch a volunteer-based early detection program as a complement the existing <a href="wsg.washington.edu/crabteam">WSG Crab Team monitoring network</a>.

Molt Search aims to support broader participation in early detection along inland Washington’s shorelines by teaching volunteers simple, standardized steps for searching and reporting on the presence (and absence!) of European green crab molts. Molts can serve as an early indicator of the presence of European green crab in a new area. Additional data on native Dungeness crab molts adds value to search efforts by filling a significant knowledge gap on the range and growth patterns of juvenile Dungeness, whose preferred habitats overlap with the new invader.

Molt Search reports consist of a small amount of metadata (e.g. location, time, optional measurements) and an overhead photograph of all molts collected during a standardized time. Submissions are made via the <a href="https://www.mycoast.org/wa/crab">MyCoast app or website</a> and are available there once published publicly following review, currently done manually by Washington Sea Grant staff.
